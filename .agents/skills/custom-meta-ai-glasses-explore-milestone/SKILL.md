# Custom Meta AI Glasses Explore Milestone

Run one bounded first generalized Project Interaction workflow. This skill coordinates specialists; it never edits production code itself.

## Authority and fixed scope

- Read `AGENTS.md`, `docs/PROJECT_INTERACTION_FOUNDATION.md`, `docs/PROJECT_MEMORY_ARCHITECTURE.md`, `docs/ROADMAP.md`, and `docs/project_constitution.md`.
- Preserve unrelated repository work and all human approval boundaries.
- The proof is limited to Room Redesign: explicit Project-scoped EXPLORE request, deterministic Context Pack, one provider-neutral call, `OPTION_SET | INFORMATION_REQUEST`, ordered AI/inferred Idea Activities, explicit user dispositions, existing Idea promotion, and restart reconstruction.
- Exclude Research, Compare, Guide, Plan, media/YouTube/shopping, clients/glasses, new persistence, automatic routing, and generalized workflow infrastructure.
- Product Ideas cannot enter Triage or Development without explicit human promotion.

## Default read-only pipeline

Run these roles read-only and consolidate their evidence:

1. `$custom-meta-ai-glasses-product-designer`
2. `$custom-meta-ai-glasses-information-architect`
3. `$custom-meta-ai-glasses-trust-ux-reviewer`
4. `$custom-meta-ai-glasses-cross-device-designer` only when more than one device surface is actually in the authorized milestone
5. `$custom-meta-ai-glasses-scope-guardian`
6. `$custom-meta-ai-glasses-explore-architect`
7. `$custom-meta-ai-glasses-structured-output-validator`
8. `$custom-meta-ai-glasses-interaction-persistence-auditor`
9. `$custom-meta-ai-glasses-explore-ux-tester`
10. Combine and deduplicate findings without weakening classifications.
11. `$custom-meta-ai-glasses-triage` produces exactly one bounded implementation batch.
12. Stop for human approval. Do not invoke Development by default.

## Authorized implementation mode

Only when the user explicitly authorizes the consolidated batch:

13. `$custom-meta-ai-glasses-development` implements that batch.
14. `$custom-meta-ai-glasses-architecture-guardian` reviews independently.
15. Development may repair only blocking findings inside the same batch.
16. Rerun affected product/technical specialists once.
17. `$custom-meta-ai-glasses-qa-breaker` runs bounded regression review.
18. `$custom-meta-ai-glasses-demo-scenario-designer` evaluates the scenario proof.
19. Return final readiness, both repository statuses, remaining risks, and physical/client exclusions.
20. Stop.

There is no autonomous second repair cycle. A second implementation batch requires new human authorization. Commits, pushes, deployment, provider/configuration changes, and Project-data mutation also require explicit authority.

## Report

Return product findings, technical contracts, deduplicated issues, the single triage batch, human-approval status, any authorized implementation/validation, specialist reruns, readiness, exclusions, and repository status.
